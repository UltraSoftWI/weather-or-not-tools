# Weather or Not · Tools

The working tools behind [Weather or Not with Miso](https://www.youtube.com/@Weatherornot-miso), a Massive Vivid Pictures project. Live at https://ultrasoftwi.github.io/weather-or-not-tools/

- `weather/` — Weather Studio: the six-part forecast brief each script is written from (Open-Meteo + National Weather Service), for Dane County Regional Airport, Madison WI.
- `backgrounds/` — Background Sets: 40 fall plates, ten weathers × day/night × ship deck/cabin.
- `thumbnails/` — Thumbnail Studio: one YouTube thumbnail layout for every episode.

Case study: https://stanislawrobertluberda.com/weather-or-not/
